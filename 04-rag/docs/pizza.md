# Pizza notes (distractor)

This file is intentionally unrelated to LLM APIs. It exists so retrieval
can be tested: a question about tokens should not rank this file first.

Neapolitan pizza is baked very hot and is usually topped with tomato,
mozzarella, and basil. New York slices are larger and often eaten folded.
A calzone is a folded pizza, not a chat completion.
